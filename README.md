# Python Data Engineering Learning

Hands-on learning repository for building practical Python skills for Data Engineering.

The goal of this repository is not to complete another Python course.  
The goal is to develop enough Python engineering competence to independently build, test, debug, and explain a reliable local data pipeline.

## Target Outcome

The Python learning phase culminates in an end-to-end pipeline:

```text
Public REST API
        ↓
Raw JSON
        ↓
Validation
        ↓
Clean / Standardized Data
        ↓
Business Transformation
        ↓
PostgreSQL + Parquet
        ↓
Data Quality
        ↓
Logging + Tests
