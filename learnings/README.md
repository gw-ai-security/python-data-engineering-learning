# Learnings

Dieser Ordner ist das Nachschlagewerk für die Python-Phase. Die Texte sind bewusst kurz, verständlich und auf Data Engineering ausgerichtet. Code und Bezeichner bleiben überwiegend Englisch.

Jeder Block enthält:

- **Wozu dient das?**
- **Mental Model**
- **Kernkonzepte**
- **kleine Codebeispiele**
- **Data-Engineering-Transfer**
- **typische Fehler**
- **Recall-Fragen**
- **Gate / Definition of Done**
