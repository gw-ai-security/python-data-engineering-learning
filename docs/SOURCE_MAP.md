# Source Map

The repository documentation is a concise, original synthesis of the learning sources. It does not reproduce full transcripts or course materials.

## Primary concept source

**Data with Baraa – Python Course**  
Role: Python fundamentals, thinking layers, data handling, execution flow, data structures and functions.

Core course structure:

- Foundations
- Strings and Numbers
- Boolean / Operators
- Conditions
- Loops
- Data Structures
- Functions

## Practice source

**Asabeneh – 30 Days of Python**  
Role: exercise bank, additional explanations and no-template transfer tasks.

It is deliberately re-sequenced for Data Engineering; see `COURSE_STRUCTURE.md`.

## Data Engineering bridge sources

**Python 2026 Beginner to Advanced**  
Role: files, errors, logging, debugging, pandas, databases, APIs, OOP basics, performance and production-oriented practices.

**Data-Movies-Baraa**  
Role: pipeline big picture, Sources → Extract/Load → Clean/Enhance → Business Transformation, config/logging/data quality and separation of concerns.

**Data Architect / Data Architecture sources**  
Role: requirements thinking, architecture thinking, trade-offs and documentation.

## Learning-system sources

**Roadmap v2.0** – sequence, 20/80 practice rule, gates and project target.  
**AI Engineering** – specification, verification, no-AI reproduction and AI-assisted engineering.  
**Learning Compass** – convert confusion into precise questions.  
**Infos / project context** – Git, documentation, security and evidence as cross-cutting practices.

## Reused prior knowledge

Existing SQL, Data Warehouse and Data Modeling work is reused for:

- grain;
- raw / clean / business-ready separation;
- data quality;
- reconciliation;
- business rules;
- lineage;
- naming standards;
- documentation.

## Technical-reference rule

When implementation details depend on a changing library, current official documentation for that library is the technical reference. The learning sources define the concepts, sequence and competence gates.
